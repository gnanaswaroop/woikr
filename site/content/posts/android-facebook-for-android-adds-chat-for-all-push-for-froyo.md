<g:plusone size="medium"></g:plusone></li><li></li></ul><p style="text-align: justify;">Facebook’s native Android app got updated to 1.5 today. The official changelog includes the following new features:</p>
<ul style="text-align: justify;">
<li>Chat support with background mode (receive chat messages while using other applications)</li>
<li>Push Notifications support for Froyo+ (2.2+) devices only (receive notifications instantly)</li>
<li>Various bug fixes</li>
</ul>
<p style="text-align: justify;">I’m glad to see that Facebook is taking the Android app seriously since the last few months.</p>
