<p>With hardware companies getting into the “Android Media player” gadgets like <a href="/android/samsung-announces-yet-another-ipod-touch-killer-to-be" target="_blank">this</a>, and screen sizes on mobile phones and tablets growing bigger it’s time Android get serious about the phone being used as a complete media player.</p>
<p>A leaked video surfaced which supposedly shows a revamped music player experience in the upcoming Android version (3.0 – honey comb) to be a head-on competition to the music dominator Apple’s iPod.</p>

<p>We’ve heard of these arguments before. Apple’s strategy was an all-in-one approach to tackle this which goes something like this "Give out the best software and hardware and provide great integration with online music/video stores", it's been successful at it so far.</p>
<p>Android is going to get it’s own online store too, but more details will only be revealed later.</p>
<p>Still hate the Android’s default media player? There are other applications available like <a href="http://www.winamp.com/android" target="_blank">Winamp</a> which even offer wireless synchronization with your desktop PC.</p>
