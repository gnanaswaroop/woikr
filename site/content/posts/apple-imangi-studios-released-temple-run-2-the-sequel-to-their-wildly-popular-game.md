<p style="text-align: justify;"><a href="http://www.imangistudios.com">Imangi Studios</a> surprised everyone by releasing <a href="https://itunes.apple.com/us/app/temple-run-2/id572395608?mt=8">Temple Run 2</a> – the sequel to their wildly popular game, <a href="https://itunes.apple.com/us/app/temple-run/id420009108?mt=8">Temple Run</a>. The original game was a huge hit because of its immersive and thrilling, yet simple gameplay. The sequel is no different. It improves upon the prequel with astoundingly better graphics (which are, apparently, built using a much better graphics engine this time), new power ups, new stunts, yet using the same simplistic controls.</p>
<p style="text-align: justify;"><img title="temple-run-2-iOS.png" src="/wp-content/uploads/2013/01/temple-run-2-iOS.png" alt="temple run 2 for iOS" width="270" height="480" border="0"></p>
<p style="text-align: justify;">You can download the iOS version from here:&nbsp;<a href="https://itunes.apple.com/us/app/temple-run-2/id572395608?mt=8">https://itunes.apple.com/us/app/temple-run-2/id572395608?mt=8</a>. The Android version will be released in some time.</p>
