Apple unveiled upgrades to the Macbook Pro 13, 15 and 17 inch models to a better hardware. They now have better dual and quad core processors and a thunderbolt port.

<a href="/wp/wp-content/uploads/2011/02/Macbookprolinedup.jpg"><img title="Macbook-pro-lined-up" src="/wp/wp-content/uploads/2011/02/Macbookprolinedup_thumb.jpg" alt="Macbook-pro-lined-up" width="390" height="215" /></a>

&nbsp;



&nbsp;

<strong>Hardware Upgrades were</strong>
<ul>
	<li>
<div><strong>Processor
</strong>The 13" inch have been upgraded to Core i5 Dual Core processor and
15 and 17 inchers have been upgraded to Core i7 Quad Core processors with the new Intel’s Sandy Bridge.</div></li>
	<li>
<div><strong>Graphics</strong>
Intel HD Graphics 3000/ AMD Radeon HD – For 3x graphics compared to the old MBP.</div></li>
	<li>
<div><strong>High Speed Thunderbolt ports
</strong>The first laptops to have Intel’s LightPeak high speed data port which supports speeds upto 10Gbps</div></li>
	<li>
<div><strong>HD Camera</strong>
For the HD FaceTime goodness. For those with just a MacBook you can download the FaceTime application from the AppStore for 99 cents.</div></li>
</ul>
<a href="/wp/wp-content/uploads/2011/02/MacbookProSideports.jpg"><img title="Macbook-Pro-Side-ports" src="/wp/wp-content/uploads/2011/02/MacbookProSideports_thumb.jpg" alt="Macbook-Pro-Side-ports" width="536" height="87" /></a>

<strong>Available in the configuration</strong>
<ul>
	<li>
<div>13.3-inch display, 2.3GHz dual-core Core i5, 4GB DDR3 RAM, 320GB HD, Intel HD Graphics 3000 — $1,199</div></li>
	<li>
<div>13.3-inch display, 2.7GHz dual-core Core i5, 4GB DDR3 RAM, 500GB HD, Intel HD Graphics 3000 — $1,499</div></li>
	<li>
<div>15.4-inch display (1440×900), 2.0GHz quad-core Core i7, 4GB DDR3 RAM, 500GB HD, AMD Radeon HD 6490M  — $1,799</div></li>
	<li>
<div>15.4-inch display (1440×900), 2.2GHz quad-core Core i7, 4GB DDR3 RAM, 750GB HD, AMD Radeon HD 6750M — $2,199</div></li>
	<li>
<div>17-inch display (1920×1200), 2.2GHz quad-core Core i7, 4GB DDR3 RAM, 750GB HD, dual graphics processors with automatic switching (Intel HD Graphics 3000 and AMD Radeon HD 6750M) — $2,499</div></li>
</ul>
One thing that made me happy was that, for the first time Apple's India website also showed the MacBook Pro models. The downside to this was that iStore Hyderabad guys were clueless about the upgrade (forget telling me the India prices – they're not updated on Indian website yet).
