<p><img title="image" height="200" alt="image" src="/wp/wp-content/uploads/2010/04/image19.png" width="200" /> </p>  <p><a href="http://www.irctc.co.in" target="_blank">irctc.co.in</a> brought a revolution in India when it first launched the facility to book tickets for <a href="http://indianrail.gov.in" target="_blank">Indian Railways</a> over the internet. Although the site has been updated a number of times to upgrade on functionality and looks, it still lacks the elegance &amp; intuitiveness of a modern day web 2.0 site. Subsequently, many tech savvy users (including me) prefer to book their tickets at <a href="http://www.cleartrip.com" target="_blank">cleartrip.com</a> or other more intuitive sites which offer a more ajaxy and new tech interface which is simple and cool to use.</p>  <div></div>  <p>Not anymore! Check out the <a href="http://www.irctc.co.in/cgi-bin/beta.dll/irctc/services/home.do" target="_blank">beta version of irctc.co.in</a>. The new beta version has a much cleaner and neat interface. It is based on AJAX which means you can book your tickets in fewer pages and fewer clicks. The home page (Plan my travel) looks like this:</p>  <p><a href="/wp/wp-content/uploads/2010/04/image20.png"><img title="image" height="294" alt="image" src="/wp/wp-content/uploads/2010/04/image_thumb11.png" width="500" /></a></p>  <p>Unlike the old interface, the train search results and availability are displayed in the same page. There is no longer a need to specify the class of travel while searching as all the available classes are displayed in the results. Clicking on the respective radio button for a class displays the fare and availability on the selected date plus five days in advance. You can also hover over the Fare Summary link to get the breakup of the fare.</p>  <p><a href="/wp/wp-content/uploads/2010/04/image21.png"><img title="image" height="431" alt="image" src="/wp/wp-content/uploads/2010/04/image_thumb12.png" width="500" /></a> </p>  <p>Clicking on Book for a particular day will take you to the booking screen which is pretty much similar to the current one:</p>  <p><a href="/wp/wp-content/uploads/2010/04/image22.png"><img title="image" height="488" alt="image" src="/wp/wp-content/uploads/2010/04/image_thumb13.png" width="500" /></a> </p>  <p>The remaining screens are also similar to the current ones, only neater and much more readable, thanks to the choice of minimalistic colors. Note that you can book tickets through the beta site. The beta label merely indicates that there might be some minor issues with the site which the team is fixing.</p>  <p>What is interesting to note is that both current and beta versions of irctc.co.in now <a href="http://www.irctc.co.in/Compatible_browser.html" target="_blank">support almost all the browsers</a>:</p>  <p><img title="image" height="190" alt="image" src="/wp/wp-content/uploads/2010/04/image23.png" width="417" /> </p>  <p><a href="http://irctc.co.in" target="_blank">irctc.co.in</a> is one of the best and most successful internet initiative from the Government of India. It is good to see that the team is keeping itself abreast with the latest technologies and trends.</p>  <p></p>  <p></p>  <p></p>  <p></p>  <p>[via <a href="http://www.irctc.co.in" target="_blank">irctc.co.in</a>]</p>
