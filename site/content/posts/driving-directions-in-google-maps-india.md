<p><a href="http://maps.google.co.in" target="_blank">Google Maps India </a>can now give you driving directions. The feature which defines the very purpose of online maps is thankfully now available for Indian users:</p>

<a href="/wp/wp-content/uploads/2009/03/google_maps_india_directions.png"><img class="alignnone size-medium wp-image-2398" title="google_maps_india_directions" src="/wp/wp-content/uploads/2009/03/google_maps_india_directions-217x300.png" alt="google_maps_india_directions" width="217" height="300" /></a>
<p><a href="/wp/wp-content/uploads/2009/03/google_maps_india_directions.png"></a>You can get driving directions in all the major cities of India. This is pretty cool. However, since not all the roads in India are named or numbered yet, you might have to do with direction and length based routes in many places for now:</p>

<a href="/wp/wp-content/uploads/2009/03/google_maps_india_directions1.png"><img class="alignnone size-medium wp-image-2397" title="google_maps_india_directions1" src="/wp/wp-content/uploads/2009/03/google_maps_india_directions1-194x300.png" alt="google_maps_india_directions1" width="194" height="300" /></a>
<p>What's really cool is that this feature is now also available on the iPhone. Since iPhone uses Google Maps, you will be able to use this feature without having to upgrade the firmware (that is, if you are not on an archeological firmware):</p>

<a href="/wp/wp-content/uploads/2009/03/google_maps_india_directions_iphone.png"><img class="alignnone size-medium wp-image-2396" title="google_maps_india_directions_iphone" src="/wp/wp-content/uploads/2009/03/google_maps_india_directions_iphone-200x300.png" alt="google_maps_india_directions_iphone" width="200" height="300" /></a>
<p>Let's hope the next government does a better job in naming and numbering the Indian roads so that we can finally use such features in India.</p>
