<div><strong>Browser features </strong></div>
<strong>History:<br>

Otherwise, it looks good and search works perfectly. Just like <a href="http://desktop.google.com/" target="_blank">Google Desktop Search</a>. Firefox does the job as well. It's more or less a tie, except for those like me who hate the separate tab for History.

<strong>Bookmarks:<br>
</strong>Well, this is good. A dropdown as it should be.<br>
But wait, I can't click the middle mouse button to open all links in a folder. Heck, there seems to be no way to do this. Adding a bookmark is exactly same as Firefox 3. I can't find any Bookmarks manager though, strange! The editing is really trivial, no options at all. But it isn't bad.<br>
Overall, It seems Firefox wins again, marginally this time though.

<a href="/wp/wp-content/uploads/2008/09/bookmarks-chrome.png"><img src="/wp/wp-content/uploads/2008/09/bookmarks-chrome-thumb.png" alt="bookmarks_chrome" width="270" height="182" /></a>

<strong>Downloads:</strong><br>
I have high aspirations here. I just hate how browsers handle downloads.<br>
Aargh! struggling again to reach Google Desktop's download page. It's final. I hate OmniBox.<br>
Anyway, download starts with a cute animation and a new download bar pops up in bottom. Pretty nice.<br>
Oh, I can't right click the download box, I have to explicitly click on the arrow next to it. No problem, there you go.

<a href="/wp/wp-content/uploads/2008/09/downloads-cancnel-chrome.png"><img src="/wp/wp-content/uploads/2008/09/downloads-cancnel-chrome-thumb.png" alt="downloads_cancnel_chrome" width="380" height="98" /></a>

I see no Pause button. No problem again. I'll open the downloads tab (linked on the right of the Download bar).<br>
Here's the Downloads tab. It looks really good. Better than the Firefox popup.

<a href="/wp/wp-content/uploads/2008/09/downloads-chrome.png"><img src="/wp/wp-content/uploads/2008/09/downloads-chrome-thumb.png" alt="downloads_chrome" width="455" height="236" /></a>

This Downloads UI is not really polished. No multiple select possible. No "delete all downloaded/canceled" options. And the right click is not natural. Makes me realize that this is a web-app not an actual application. Oh yes, no clean download progress bar too!<br>
Also, I can't resume canceled downloads. So cancel is like the never-press-me button.

Anyhow, the Downloads tab looks promising. I'm sure they can fix these small issues in later releases.

<strong>Search in page</strong>:<br>
Works exactly like Safari. I love it. I always wanted Firefox to have this.

<a href="/wp/wp-content/uploads/2008/09/search-page-chrome.png"><img src="/wp/wp-content/uploads/2008/09/search-page-chrome-thumb.png" alt="search_page_chrome" width="374" height="272" /></a>

<strong>File menu</strong>:<br>
Doesn't exist. Just a small dropdown on right with common options. Learnt from IE 7 and improved tremendously. I love this too.

<strong>Recovery features</strong>:<br>
I closed a full window with 12 tabs and it didn't warn or anything. There was no restore option when I opened up again.<br>
But when a Chrome window crashes, it asks you to Restore from the backup it has made. Just as expected. Firefox wins by a little margin.

<strong>Status Bar:</strong><br>
I love the status bar that appears only when required. The more screen estate, the better. Especially for widescreen displays.

<strong>Incognito</strong>:<br>
Now this sure is a cool new feature. Open a new Incognito window and browser won't any history for this particular window. So now you don't need to clear the <em>you-know-what</em> history every time before someone uses your computer.

<a href="/wp/wp-content/uploads/2008/09/incognito_chrome.png"><img class="alignnone size-full wp-image-913" title="Incognito mode" src="/wp/wp-content/uploads/2008/09/incognito_chrome.png" alt="" width="455" height="420" /></a></li>
	<li> <strong>Browser Options</strong>
<p>The option screen is very similar to Firefox 3, except some re-arrangements. I can see that they've done this to make it easier for the non-technical crowd. It works well too.<br>
But the geeky crowd will find this new arrangement clumsy.</p>
<a href="/wp/wp-content/uploads/2008/09/options-hood-chrome.png"><img src="/wp/wp-content/uploads/2008/09/options-hood-chrome-thumb.png" alt="options_hood_chrome" width="455" height="481" /></a></li>
	<li> <strong>Performance</strong>
<p>This is something which everyone hates about Firefox. The extreme memory footprint. And Google Chrome really trumps Firefox in this category. As expected from the new architecture, the sluggishness is non-existent. With as many as 10 tabs (including 3 long flickr pages full of images) Chrome works smooth. The only noticeable lag is in rendering, which seems to become slower as we open more tabs. This is expected due to the multiple processes running in parallel and is pretty reasonable.</p>
Also, either I am too sleepy or I can actually see the rendering process switching contexts between tabs. Please confirm if you feel that too (Only visible when lots of tabs are open).To top it all, Google Chrome consumes much lesser memory than Firefox with same no. of tabs (with same content) open. In my tests it's almost 30% lesser with around 10 tabs open.

And yes, it shows multiple process entries for each tab (as expected), so it can be a bit confusing. When, say you want to kill a certain process, but can't because all processes are called "chrome.exe".
<div><img class="size-medium wp-image-902 alignnone" title="chrome-multi-tabs" src="/wp/wp-content/uploads/2008/09/chrome-multi-tabs-300x97.png" alt="Multiple Tabs and Multiple=" /></div>
<div></div></li>
	<li> <strong>Conclusion</strong>
<p>That covers everything I found interesting about the new Google Chrome. It sure has it's issues and I won't be switching from Firefox anytime soon. But all these issues are very fixable. Once Google irons them out, Chrome will undoubtedly jump ahead of the competitors. After all, it is built on an <a href="http://www.google.com/googlebooks/chrome/" target="_blank">amazing design</a> and <a href="http://webkit.org/" target="_blank">foundation</a>.</p>
Without doubt this is Google's best product announcement since a long time.</li>
</ul>
