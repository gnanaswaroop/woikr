<p>An XDA developer has ported the new Gingerbread stock keyboard for Eclair and Froyo devices. We've heard only good things about it, so there is no harm in giving it a try. It definitely is much better than the previous Stock keyboard. I personally use and like the <a href="http://forum.xda-developers.com/showthread.php?t=663608" target="_blank">HTC_IME keyboard</a> but I'll give this a shot too. You can also try <a href="http://swypeinc.com/" target="_blank">Swype</a> for a different experience or <a href="http://www.the8pen.com/" target="_blank">8Pen</a> for an <em>entirely </em>different experience.</p>
<p>Download links for <a href="http://www.multiupload.com/RBG15O1Y5E">Froyo</a> and <a href="http://www.multiupload.com/OSAKU5XX1R">Eclair</a>.</p>
<p><strong>UPDATE: </strong>I installed and tried the keyboard on my Samsung Galaxy Spica. Works perfectly fine. And the first impression is quite good!</p>
<p><strong>UPDATE: </strong><a href="http://www.megaupload.com/?d=4BJYQKSW" target="_blank">Stripped down English only version for Eclair</a>. No vibrate too but consumes half the memory. Thanks <a href="http://forum.samdroid.net/f10/gingerbread-keyboard-ported-froyo-eclair-stripped-version-here-3536/" target="_blank">Kenshin</a>!</p>
