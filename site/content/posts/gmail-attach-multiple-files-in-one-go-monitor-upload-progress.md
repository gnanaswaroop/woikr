<p>This is something I have been cribbing about all the time in web based email systems. Whenever I have to attach multiple files to an email, I have to select each of them individually. Not from today.</p>
<p><a href="/tag/gmail/" target="_blank">Gmail</a> has added a new feature which lets you select multiple files at one go from the browse window. Just hold down Ctrl (Cmd on OS X) and click on each file you want to attach to your message. You can also use Shift to select continuous list of files.</p>

<a href="/wp/wp-content/uploads/2009/02/gmail-multiselect.jpg"><img class="alignnone size-full wp-image-2172" title="gmail-multiselect" src="/wp/wp-content/uploads/2009/02/gmail-multiselect.jpg" alt="gmail-multiselect" width="414" height="160" /></a>
<p>What's more, you will also see a progress bar which tells you how much each of the file has been uploaded. A real time saver. Great for sending those family vacation pictures.</p>

<a href="/wp/wp-content/uploads/2009/02/gmail_progress_bars.jpg"><img class="alignnone size-full wp-image-2171" title="gmail_progress_bars" src="/wp/wp-content/uploads/2009/02/gmail_progress_bars.jpg" alt="gmail_progress_bars" width="414" height="160" /></a>
<p>It might not be a mere coincidence that this feature is released the day after the<a href="http://venturebeat.com/2009/02/24/where-were-you-during-the-great-gmail-outage-of-february-2009/" target="_blank"> Great Gmail Outage of 2009</a>. I believe companies keep such highly anticipated features in standby in their pockets to save the day after such disasters.</p>
