<p><a href="http://en.wikipedia.org/wiki/Siri_(software)#iOS_integration" target="_blank">Siri</a> is one of the most useful and advertised features of iPhone 4S. Siri offers interactive conversations with applications like weather, email, SMS and more. Although this feature is officially only available on the iPhone 4S, jailbreak enthusiasts have been successful at <a href="http://newyork.ibtimes.com/articles/241522/20111101/install-siri-iphone-4-3gs.htm" target="_blank">porting Siri</a> to the iPhone 3GS/4 and iPod Touch.</p>  <p><a href="http://applidium.com/" target="_blank">Applidium</a>, a french mobile development company (which brought us the famous iOS game <a href="http://itunes.apple.com/us/app/falldown-3d/id424612092?mt=8" target="_blank">Falldown 3D</a>) has been successful at <a href="http://translate.google.com/translate?sl=auto&amp;tl=en&amp;js=n&amp;prev=_t&amp;hl=en&amp;ie=UTF-8&amp;layout=2&amp;eotf=1&amp;u=http%3A%2F%2Fapplidium.com%2Fnews%2Fcomment_dechiffrer_siri%2F&amp;act=url" target="_blank">reverse engineering</a> how Siri communicates with the Apple servers. The findings are pretty interesting.</p>  <p><a href="/wp/wp-content/uploads/2011/11/Siri-Make-Me-A-Sandwich.png"><img title="Siri-Make-Me-A-Sandwich" alt="Siri-Make-Me-A-Sandwich" src="/wp/wp-content/uploads/2011/11/Siri-Make-Me-A-Sandwich_thumb.png" width="338" height="234" /></a></p><p></p>  <p><strong>How Siri works -</strong> </p>  <ul>   <li>     <div>Siri records and sends audio data in a compressed encoded format like any VoIP service – Keep an eye on your data usage, you don't want to get billed crazy. With improved hardware on the iPhone 4S, the conversion from voice to text on the device itself should be possible too. </div>   </li>    <li>     <div>Siri requires a unique id from a real iPhone 4S for the successfully talking to the server. </div>   </li>    <li>     <div>Siri uses a modified HTTP protocol to communicate with the Apple Siri server - guzzoni.apple.com. The data is encrypted when transmitting. </div>   </li>    <li>     <div>Siri can be misled to connect to a local HTTPS server (using a fake DNS server) if a custom root certificate for guzzoni.apple.com is injected on the iPhone. This is like a &quot;<a href="http://en.wikipedia.org/wiki/Man-in-the-middle_attack" target="_blank">Man-in-the-middle attack</a>&quot;. Which also means that the encrypted data can be intercepted and the data de-encrypted on the local HTTPS server which uses the same custom root certificate imported on the phone. </div>   </li>    <li>     <div>Apple may block (the iPhone 4S's unique id) or change the existing Siri protocol which may inturn breaks this protocol.</div>   </li> </ul>  <p><strong>How can this be used?</strong></p>  <p>This protocol understanding enables Siri to be ported to any Mobile phone or a PC. You will still need a unique id of an iPhone 4S (has to be jailbroken to fetch the id). This even helps write custom commands which are intercepted by the server. </p>  <p>An enthusiastic hacker (<a href="https://twitter.com/#!/applidium/status/138037756445196288" target="_blank">@Plumoni</a>) has created a <a href="https://github.com/plamoni/SiriProxy" target="_blank">Siri proxy server</a> to intercept Siri's communication with Apple's servers. The developer was able to route Siri's voice commands from the proxy server to his WiFi enabled thermostat to adjust the temperature. </p>  <p>Pretty cool eh? Catch the video below. </p>   <p>I can imagine other developers writing custom Siri commands to type emails, sending IMs, tweeting on their computers pretty soon. I'd love to be able to turn on my car with a voice command from Siri. </p>  <p>May be even support Siri for unsupported languages (say French) using a 3rd party speech to text API which outputs the text which is then translated to English, passed to Siri and then data sent back to the phone in French as text (Siri won’t be able to pronounce French yet). </p>  <p><strong>How can I do it too?</strong></p>  <p>While it may take more time for this to be &quot;one-click&quot; friendly, If you're the enthusiastic type – go ahead and try these <a href="https://github.com/applidium/Cracking-Siri" target="_blank">tools</a>.</p>  <p>[Via <a href="http://www.iphonehacks.com/2011/11/hacker-creates-a-proxy-server-for-siri-to-easily-add-new-functionality-demos-controlling-a-wi-fi-thermostat.html" target="_blank">iPhoneHacks</a> and <a href="https://twitter.com/#!/applidium" target="_blank">@Applidium</a>, Original picture &quot;Sandwich&quot; by <a href="http://xkcd.com/149/" target="_blank">XKCD</a>]</p>
