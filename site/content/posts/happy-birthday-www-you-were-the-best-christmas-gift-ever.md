<p>20 years ago on the same day at <a href="http://www.google.co.in/url?sa=t&amp;source=web&amp;cd=1&amp;ved=0CBkQFjAA&amp;url=http%3A%2F%2Fwww.cern.ch%2F&amp;ei=SwUWTa7dIIrrrQflwdD9Cw&amp;usg=AFQjCNH2ifeWAgK7w0t_SlAiQzvAZu4kAQ&amp;sig2=iYEfOBIK8d6BBuAG46hcVA" target="_blank">CERN</a> in Geneva,  Tim Berners Lee and Robert Cailliau got the first Web Browser, Web Server and the Web Pages ready and published and accessed the first website. Hence was born the <a href="http://en.wikipedia.org/wiki/World_Wide_Web" target="_blank">WWW</a> (World Wide Web, also know as The Web). The web that we access day in and out. The web that provides us with all the information we could ever need. The web that has made communication entirely different than anybody ever imagined. The web that has become so big that it can scare the hell out of the most powerful people in the world. The web that has become essential for our very existence.</p>
<p><a href="/wp/wp-content/uploads/2010/12/www_oldest.png"><img title="www_oldest" src="/wp/wp-content/uploads/2010/12/www_oldest-300x220.png" alt="World Wide Web original Logo" width="300" height="220" /></a></p>
<p>Of course, then it was just a system that allowed documents with hypertext i.e. a way to link to each other. This system was accessible through a web browser by anyone with access to Internet. Nobody ever imagined that it could grow into a system where billions of users view and publish all kinds of information media. In fact in the coming future, it might well replace the whole list of software that can be used on a computer.</p>
<p>We wish the WWW stays open, stays clean and keeps growing forever.</p>
