<p>I have always had a pet peeve against Google Chrome on Mac. If I press Command + Q, it just quits without warning. In many cases this makes me lose application state or text that I typed.</p>
If you've had the same problem, I have good news for you. The latest version of Google Chrome (10) includes a solution for this. It's not enabled by default though. Here is how to do it:<br>

<ol>
	<li>Enter “about:flags” in your Chrome address bar. You will see a page with some experimental settings with a statutory warning. Don’t worry about it.<br>
<a href="/wp/wp-content/uploads/2011/01/chrome_about_flags.jpg"><img title="chrome_about_flags" src="/wp/wp-content/uploads/2011/01/chrome_about_flags-300x37.jpg" alt="Chrome about:flags" width="300" height="37" /></a></li>
	<li>Look for “Confirm to Quit” somewhere in the middle of the list and Enable it. Restart Chrome.</li>
	<li>And you are done!</li>
</ol>
<p>Now when you press Command + Q, Chrome will show you a warning message and ask you to hold Command + Q for some time if you want to quit the browser. It will feel a bit awkward for some time but you'll get the hang of it. It's much better than losing the browser state accidentally.</p>
