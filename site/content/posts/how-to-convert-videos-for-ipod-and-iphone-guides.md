<p>iTunes is a clumsy app. In all the hoopla of iPhone App Store and video rentals, Apple has apparently lost focus on one of the core jobs of iTunes - Convert &amp; Sync content to iPods and iPhone. Try converting a video to iPod foirmat in iTunes and you will know what I am saying. This is where 3rd party software come handy.</p>
<p><a href="http://www.videora.com/en-us/Converter/iPod/" target="_blank">Videora iPod video converter</a> is a tool to convert videos to iPod (and many other devices) format. It is one of the very few free apps which enable us to accomplish this task. The interface for Videora is not very intuitive. A newbie can always get lost as to where to click, how to create and manage queue etc. This tutorial will help you convert videos into iPod &amp; iPhone format using version 3.07 of this software.</p>

<ol>
	<li><a href="http://www.videora.com/en-us/Converter/iPod/download.php" target="_blank">Download</a> and install Videora iPod Video Converter.</li>
	<li>On the first run, you will be asked to select your iPod model. You can select any one as we will not be using this setting to convert our videos.</li>
	<li><strong>Create Profiles:</strong>
<ol>
	<li>Once you reach the home screen, click Settings in the Menu bar.<a href="/wp/wp-content/uploads/2008/10/home-screen.png"><img class="alignnone size-medium wp-image-1163" title="home-screen" src="/wp/wp-content/uploads/2008/10/home-screen-300x196.png" alt="" width="300" height="196" /></a></li>
	<li>On the settings page, click on New Profile.<br>
<a href="/wp/wp-content/uploads/2008/10/settings.png">
<img class="alignnone size-medium wp-image-1162" title="settings" src="/wp/wp-content/uploads/2008/10/settings-300x236.png" alt="" width="300" height="236" /></a></li>
	<li>In the dialog box which appears, enter the profile name iPod 4:3. Leave the rest of the fields intact and click on Video in the Menu Bar.<a href="/wp/wp-content/uploads/2008/10/add-profile-1.png"><img class="alignnone size-medium wp-image-1161" title="add-profile-1" src="/wp/wp-content/uploads/2008/10/add-profile-1-300x201.png" alt="" width="300" height="201" /></a></li>
	<li>Make sure the Video Codec is H.264 &amp; Max Resolution is 320x240. Also, the bitrate should be 768 kbps. Once done, click on Audio in the menu bar.<a href="/wp/wp-content/uploads/2008/10/add-profile-2.png"><img class="alignnone size-medium wp-image-1159" title="add-profile-2" src="/wp/wp-content/uploads/2008/10/add-profile-2-300x169.png" alt="" width="300" height="169" /></a></li>
	<li>Change the bitrate to 160. Click on OK once done.<a href="/wp/wp-content/uploads/2008/10/add-profile-3.png"><img class="alignnone size-medium wp-image-1160" title="add-profile-3" src="/wp/wp-content/uploads/2008/10/add-profile-3-300x253.png" alt="" width="300" height="253" /></a></li>
	<li>Repeat the above steps and create a new profile named "iPod 16:9" in step 3 with Max Resolution 320x180 (you will have to type it in) in step 4. Everything else remains the same.<a href="/wp/wp-content/uploads/2008/10/add-profile-4.png"><img class="alignnone size-medium wp-image-1158" title="add-profile-4" src="/wp/wp-content/uploads/2008/10/add-profile-4-300x197.png" alt="" width="300" height="197" /></a></li>
</ol>
</li>
	<li><strong>Set defaults:</strong>
<ol>
	<li>Under Settings, click on the Converter tab. Here, select a default output folder for your converted videos. Make sure to select a folder with some amount of free space. Also, select the default profile as "iPod 16:9" you created in the steps above.<a href="/wp/wp-content/uploads/2008/10/settings-defaults.png"><img class="alignnone size-medium wp-image-1157" title="settings-defaults" src="/wp/wp-content/uploads/2008/10/settings-defaults-300x235.png" alt="" width="300" height="235" /></a><br>
In the screen above, you can also select the CPU usage while converting the videos. Once finished, click on Save settings.</li>
</ol>
</li>
	<li><strong>Start Converting:</strong>
<ol>
	<li>Click on Video File tab under Convert. This will bring you to a screen below. Ignore the instructions appearing in the space above the screen.<a href="/wp/wp-content/uploads/2008/10/convert-1.png"><img class="alignnone size-medium wp-image-1156" title="convert-1" src="/wp/wp-content/uploads/2008/10/convert-1-300x254.png" alt="" width="300" height="254" /></a></li>
	<li>Click on Select File to browse &amp; select the file you want to convert.</li>
	<li>Click on Browse to select the output directory where you want to save the converted video.</li>
	<li>Enter a Title for the converted video.</li>
	<li>Select your device in the drop down.</li>
	<li>If the video is in wide screen format (two black strips on top and bottom - most new videos are wide screen), select the profile iPod 16:9. Otherwise select iPod 4:3.</li>
	<li>Now you have 2 options. You can either start converting this video immediately or add it to the queue. The first item in the queue starts converting immediately by default.<a href="/wp/wp-content/uploads/2008/10/convert-2.png"><img class="alignnone size-medium wp-image-1155" title="convert-2" src="/wp/wp-content/uploads/2008/10/convert-2.png" alt="" width="146" height="208" /></a></li>
	<li>Once you are done with this video, you can add more to the queue. Remember to select the correct profile depending on the video format. The converter remembers each video's profile setting.</li>
	<li>You can also use the Once Click convert button to simply select the video and convert it to the default format and save it in the default output folder you specified in step 4 above. This is useful if you are in a hurry and do not want to carry out all the steps above.</li>
</ol>
</li>
</ol>
<p>That's it! You can now enjoy all your favourite videos on your iPod or iPhone. Since video conversion can take a few minutes to a few hours depending on the encoding &amp; length of the source video, it is recommended that you create a queue and leave it overnight to convert all the videos. That way, you will have all your videos ready to be fed to your device when you wake up next morning.</p>
