<p>Sometimes Apple can be just plain ignorant. All these years and they still don't have a proper way to  Cut/Paste files and folders on Mac! You have to select the files, and drag them to the target location using the mouse. It makes moving files suck a pain in the ass.</p>
<p><a href="/wp/wp-content/uploads/2011/01/moveAddict_logo.jpg"><img class="alignnone size-full wp-image-6353" title="moveAddict_logo" src="/wp/wp-content/uploads/2011/01/moveAddict_logo.jpg" alt="moveAddict logo" width="169" height="154" /></a></p>
<p>Thankfully, there is a solution. Kapeli's <a href="http://kapeli.com/" target="_blank">moveAddict</a> for Mac fixes the long faced problem of Mac users. moveAddict provides the simple functionality to move files using the keyboard. You can select the files, Press "Command + X" to cut the files, select a target folder and Press "Command + V" to paste the files. It's just like Windows. You can add Cut, Copy and Paste buttons on Finder's toolbar.</p>
<p><a href="/wp/wp-content/uploads/2011/01/moveAddict_1.jpg"><img title="moveAddict_1" src="/wp/wp-content/uploads/2011/01/moveAddict_1-300x189.jpg" alt="moveAddict (Cut Paste on Mac)" width="300" height="189" /></a></p>
<p>moveAddict also adds the "merge folder" functionality when you are trying to move a folder to a location where another folder of the same name exists.</p>
