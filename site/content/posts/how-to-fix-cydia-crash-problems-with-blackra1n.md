<p>After a recent accident my old iPhone2G’s power button started to malfunction and doesn’t let me put the iPhone in DFU mode (you know for unlocking).</p>

<p>I totally agree that we should always stick to dev team’s unlocking procedure – say redsn0w. But that requires a manual step to put the phone in DFU mode. (The software approach to set the phone to DFU mode is buggy and sets the phone to recovery mode instead, you’ll have to use a software like TinyUmbrella to get the iPhone out of recovery mode if you use that)</p>
<p>So I could only stick to tethered jailbreak and unlock using <a href="/iphone/how-to-upgrade-and-unlock-your-iphone-using-blackra1n" target="_blank">blackra1n</a>. <a href="http://spiritjb.com/" target="_blank">SpiritJB</a> wasn’t working on my iPhone (shows an <a href="http://www.google.com/search?q=spirit+assert+failed" target="_blank">exception</a>)</p>

<p>After Jail breaking and unlocking my iPhone 2G on firmware 3.1.2 with blackra1n and installing Cydia from the blackra1n application it always crashes on the startup/load.</p>

<p>A <a href="http://www.google.com/search?q=blackra1n+cydia+crash" target="_blank">Google search</a> revealed that the real issue is that blackra1n doesn’t add the much required component – AFC and <a href="http://en.wikipedia.org/wiki/George_Hotz" target="_blank">GeoHot</a> refuses to give a fix for this problem. The only way is to install the AFC service using Cydia. Even the desktop iPhone explorer software like <a href="http://www.i-funbox.com/" target="_blank">iFunBox</a> or the <a href="http://code.google.com/p/iphonebrowser/" target="_blank">iPhoneBrowser</a> wouldn’t work without this service installed on the phone (shows the phone as jailed).</p>
<p>To fix the crash problem (without Cydia) is to use a previously popular way to Jailbreak the phone – <a href="http://jailbreakme.com" target="_blank">JailBreakMe.com</a>'s online jail breaking website.</p>
<p>It complains that  jail breaking an already Jail broken phone is risky. But it worked well for me. It re-installed Cydia and the AFC service along with that unlike blackra1n. This approach should work for all the iPhone(s) with firmware &lt;=4.0.2 which is the last version JailBreakMe.com supports. Remember this doesn’t unlock the iPhone without the use of UltraSn0w. Make sure you have taken backups.</p>
<p>After this Cydia worked pretty fine with me. I did install <a href="http://www.simonblog.com/2009/10/30/how-to-fix-diskaid-or-iphone-browser-issue-after-blackra1n-jailbreak/" target="_blank">afc2add</a> from Cydia again just to be safe. I am going to get the power button repaired anyway.</p>
