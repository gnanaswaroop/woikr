<p>After a lot of delays, the much awaited Android 2.3 upgrade for the <a href="/reviews/lg-optimus-one-p500-hands-on-and-review-with-pics/" target="_blank">LG Optimus One</a> has been rolled out to India too. The upgrade process is itself very simple and requires you to use LG’s phone update software.</p>  <p>It is so lame that LG still prefers to have a Windows PC USB upgrade when Android 2.2+ supports &quot;Over the Air&quot; upgrades. Other companies like HTC have adopted that right after 2.2. This is a lesson, LG has to learn to improve it's sales.</p>  <p><img alt="" src="/wp/wp-content/uploads/2010/12/LGActualPic.jpg" width="160" height="285" />&#160;<a href="/wp/wp-content/uploads/2011/09/LG-Optimus-One-Android-2.3-Upgrade.png"><img title="LG Optimus One Android 2.3 Upgrade" alt="LG Optimus One Android 2.3 Upgrade" src="/wp/wp-content/uploads/2011/09/LG-Optimus-One-Android-2.3-Upgrade_thumb.png" width="183" height="274" /></a></p>  <div></div>  <p>If your phone is Operator Locked, verify with your operator if the Android 2.3 upgrade is available for your phone (depends on the region too). If your phone is rooted, first look up if the phone can be rooted after upgrading to 2.3 and if it's safe to upgrade from 2.2 rooted.</p>  <p><strong>Steps to Upgrade to Android 2.3 Gingerbread</strong>.</p>  <ol>   <li>     <div>Download the <a href="http://www.lg.com/in/support/mc-support/mobile-phone-support.jsp" target="_blank">LG Mobile Support Tool</a> (Supports Windows OS only)        <br />This tool is later used to keep a track of all the software updates for your phone and to download the actual update. This registers itself as a start-up program which can be removed. </div>   </li>    <li>     <div>Set up Language and Country for the tool to get a list of supported phones.       <br />Open LG Mobile Support Tool and set Country and Language to India and English respectively. If you're from another region, please update accordingly. This plays a major role to check for a software update for your phone.        <br /><a href="/wp/wp-content/uploads/2011/09/LG-Mobile-Support-Tool-Country-and-Language.png"><img title="LG Mobile Support Tool - Country and Language" alt="LG Mobile Support Tool - Country and Language" src="/wp/wp-content/uploads/2011/09/LG-Mobile-Support-Tool-Country-and-Language_thumb.png" width="363" height="247" /></a></div>   </li>    <li>     <div>Download the USB Drivers and LG PC Suite IV       <br />Go to Menu &quot;Customer Support&quot; and open &quot;Application, Manual &amp; USB Driver Download&quot;        <br />Double click and download – PC Sync and USB Driver.        <br /><a href="/wp/wp-content/uploads/2011/09/LG-Mobile-Support-Tool-USB-Driver-Download.png"><img title="LG Mobile Support Tool - USB Driver Download" alt="LG Mobile Support Tool - USB Driver Download" src="/wp/wp-content/uploads/2011/09/LG-Mobile-Support-Tool-USB-Driver-Download_thumb.png" width="421" height="218" /></a></div>   </li>    <li>     <div>Disconnect the phone and Install the USB Driver and LG PC Suite.       <br />After download, the files are available at C:\LGP500 folder. The USB driver is an exe file and the LG PC Suite would be inside a zip file. The LG PC Suite is a parallel application to the LG Mobile Support Tool which helps users sync the phone data to a PC.</div>   </li>    <li>     <div>Backup using LG PC Suite       <br />You can setup contacts, calendar, bookmarks, photos, videos and SMS sync based on your need. I've only selected contacts, photos and SMSs for my phone. Wait for the Sync process to finish. There is also a way to setup Phone Sync over Bluetooth (Only phone sync, not the OTA Android update).        <br /><a href="/wp/wp-content/uploads/2011/09/LG-Optimus-One-LG-PC-Suite-Sync-Setup.png"><img title="LG Optimus One - LG PC Suite Sync Setup" alt="LG Optimus One - LG PC Suite Sync Setup" src="/wp/wp-content/uploads/2011/09/LG-Optimus-One-LG-PC-Suite-Sync-Setup_thumb.png" width="421" height="267" /></a></div>   </li>    <li>     <div>Start Upgrade       <br />Open up LG Mobile Support tool and connect your Phone back to the USB Cable. The software should recognize your phone and suggest that you're eligible for a software update. Ensure your phone battery is decently charged (&gt;= 70%) and proceed.</div>   </li>    <li>     <div>       <p>Upgrade Process         <br />The phone should show a yellow background with a message &quot;Emergency Mode&quot; for a few minutes. During this process, keep an eye on the desktop software which gives you status messages on the software upgrade process.</p>        <p>After the upgrade is complete, the phone was powered off (That’s weird) – So I powered it ON and for almost 5-10 mins it was stuck on the Android animation.         <br />Scared the hell out of me, It did sit on that for like 10 mins and then booted into the OS when I was about to pull out the battery to force hard reboot.</p>     </div>   </li>    <li>     <div>Upgrade Process Complete       <br />There is a very simple wizard which asks if you wish to continue to add email account details. I found out that none of the data was wiped off, the upgrade process retained all my contacts/settings and all the other apps with one exception. </div>   </li>    <li>     <div>Restoring from back up       <br />I didn't have to restore any thing from backup, except I now notice that they removed the previously bundled DioDict Dictionary Application. In case you are missing contacts/apps. You'd have to restore back data using the LG PC Suite. </div>   </li>    <li>     <div>Missing Anything?       <br />LG hasn't removed most crappy applications like &quot;Infant Vaccine Tracker&quot; from the 2.3 upgrade too.        <br />LG - Are you kidding me (again)?</div>   </li> </ol>  <p><strong>So What’s new in Android 2.3 Gingerbread?</strong>    <br />For the whole list of features, you should check <a href="http://developer.android.com/sdk/android-2.3-highlights.html#UserFeatures" target="_blank">this out</a>. I personally liked a few</p>  <ul>   <li>     <div>Improved text editing, you finally have a neat way to move the cursor between letters.</div>   </li>    <li>     <div><a href="/android/gingerbread-keyboard-on-eclair-froyo/" target="_blank">Gingerbread keyboard</a> which I’ve been using on Android 2.2 as well.</div>   </li>    <li>     <div>Seems fast enough (No performance difference between 2.2 and 2.3)</div>   </li>    <li>     <div>Internet calling – Supposed to have better SIP Integration, so that you can initiate internet calls right from the contact book.</div>   </li>    <li>     <div>There are other new features which can't be observed on the LG Optimus P500 – supports more cameras, NFC etc.</div>   </li> </ul>  <p><strong>Android 2.3 looks like this     <br /></strong>    <br />&#160;<a href="/wp/wp-content/uploads/2011/09/LG-Optimus-One-Android-2.3-Home-page1.png"><img title="LG Optimus One Android 2.3 Home page" alt="LG Optimus One Android 2.3 Home page" src="/wp/wp-content/uploads/2011/09/LG-Optimus-One-Android-2.3-Home-page_thumb.png" width="192" height="288" /></a>&#160;<a href="/wp/wp-content/uploads/2011/09/LG-Optimus-One-Android-2.3-Settings-Menu1.png"><img title="LG Optimus One Android 2.3 Settings Menu" alt="LG Optimus One Android 2.3 Settings Menu" src="/wp/wp-content/uploads/2011/09/LG-Optimus-One-Android-2.3-Settings-Menu_thumb.png" width="192" height="288" /></a> <a href="/wp/wp-content/uploads/2011/09/LG-Optimus-One-Android-2.3-Text-Editing-Cursor1.png"><img title="LG Optimus One Android 2.3 Text Editing Cursor" alt="LG Optimus One Android 2.3 Text Editing Cursor" src="/wp/wp-content/uploads/2011/09/LG-Optimus-One-Android-2.3-Text-Editing-Cursor_thumb.png" width="192" height="288" /></a></p>  <p>This would probably be the last Android update that LG is going to roll out for this budget (but really popular) Android phone. So, don't expect a Android 4.0 – Ice Cream Sandwich upgrade.</p>
