Have you been Facebook places religiously, then you probably also hate that Facebook.com uses Bing Maps to show you the check-in(s). This article tells you how to configure your browser to show Google Maps instead of Bing Maps.

<a href="/wp/wp-content/uploads/2011/02/FacebookPlacesGoogleMaps.png"><img title="FacebookPlacesGoogleMaps" src="/wp/wp-content/uploads/2011/02/FacebookPlacesGoogleMaps_thumb.png" alt="FacebookPlacesGoogleMaps" width="187" height="143" /></a>

If you still don't know what I mean, then check how boring a check-in to the <a href="http://www.facebook.com/pages/Statue-Of-Liberty/146321248721843" target="_blank">Statue of Liberty</a> looks on Facebook places using Bing Maps.

<a href="/wp/wp-content/uploads/2011/02/FacebookPlacesWithBingMapsStatueOfLiberty.jpg"><img title="Facebook-Places-With-Bing-Maps-Statue-Of-Liberty" src="/wp/wp-content/uploads/2011/02/FacebookPlacesWithBingMapsStatueOfLiberty_thumb.jpg" alt="Facebook-Places-With-Bing-Maps-Statue-Of-Liberty" width="452" height="204" /></a>

<strong>What's Facebook places?<br>
</strong>Facebook places is a social check-in service just like FourSquare or Gowalla. A couple of businesses reward the users (like discounts on <a href="http://www.techknots.com/mobiles/cafe-coffee-day-foursquare-mayor/" target="_blank">coffee</a>) by the visit frequency. You can <a href="/search/Facebook+Places/" target="_blank">read</a> our coverage on Facebook places.

<strong>Steps to use Google Maps in Facebook Places</strong>
<ol>
	<li>
<div>Mandatory: Verify Compatibility.<br>
For Mozilla Firefox – If you have Greasemonkey in Mozilla Firefox, Install it<br>
For Google Chrome/Chromium – check if you have version 4.0+, upgrade if not.</div></li>
	<li>
<div>Install the <a href="http://userscripts.org/scripts/show/89230" target="_blank"><strong>Facebook Places with Google Maps</strong></a> user script.<br>
You will be prompted if you trust the script, accept it (no, i don’t want to steal your password) – You can actually see the <a href="http://code.google.com/p/facebook-places-with-google-maps/" target="_blank">project source code</a> too.</div></li>
	<li>
<div>Voila, you're done. You should now be able to see a much better and bigger Google Map for the same Location. Here's how the Statue of Liberty check-in looks now.</div></li>
</ol>
