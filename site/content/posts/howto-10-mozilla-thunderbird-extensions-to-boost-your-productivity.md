<g:plusone size="medium"></g:plusone></li><li></li></ul><p>Many of us use <a href="http://www.mozillamessaging.com/en-US/thunderbird/" target="_blank">Mozilla Thunderbird</a> at work/home to check email. It’s got a great feature to extend functionality through 3rd party extensions or <a href="http://www-archive.mozilla.org/projects/thunderbird/specs/extensions.html" target="_blank">plug-ins</a>.</p>
<p><a href="/wp-content/uploads/2011/01/MozillaThunderbird.png" rel="lightbox[6386]"><img title="Mozilla-Thunderbird" src="/wp-content/uploads/2011/01/MozillaThunderbird_thumb.png" alt="Mozilla-Thunderbird" width="496" height="101"></a><br>
Here’s my pick of 10 thunderbird extensions (in no particular order) that will help you get things done quickly. These have been proven to improve productivity at work across years.</p>
<p><span id="more-6386"></span></p>
<ol>
<li>
<div><a href="http://mailtweak.mozdev.org/" target="_blank">Mail Tweaks</a> – Few tweaks to enhance your email experience, the major ones are</div>
<ul>
<li>
<div>Collected Reply – When you’re reply to more than one email where you’d want to send the same email response.</div>
</li>
<li>
<div>Message Font – Ever hated that Thunderbird never auto-selects your default font? With this you can set the font type and size  for composing.</div>
</li>
<li>
<div>Colored Replies – Do you change the email reply font color when replying? This’ll can help you do that every time.</div>
</li>
<li>
<div>Personalize messages – Do you often send Multi cast email? This plug-in would help you write “Hi %firstname%” email to automatically substitute a name of the recipient for each email sent.</div>
</li>
<li>
<div>Status Icons – Marks the emails with icons to check if an email was replied/forwarded.</div>
</li>
<li>
<div>Multiple Search Windows – We all know mailbox is full of clutter after a few years of use. This feature helps keep more than one search window open.<br>
<a href="/wp-content/uploads/2011/01/MailTweakMenu.png" rel="lightbox[6386]"><img title="Mail-Tweak-Menu" src="/wp-content/uploads/2011/01/MailTweakMenu_thumb.png" alt="Mail-Tweak-Menu" width="437" height="382"></a><p></p>
</div>
</li>
</ul>
</li>
<li>
<div><a href="http://blunderdelay.mozdev.org/" target="_blank">Blunder Delay</a><br>
People using MS Outlook would understand the comfort of sending the email in the background. Blunder Delay does exactly that for Thunderbird. You can direct the email to go to the Outbox folder and then Blunder Delay would clear out that every ‘x’ (configurable) minutes. <a href="/howto/send-emails-in-background-in-thunderbird-tips" target="_blank">Here’s</a> more details on configuring it.<p></p>
</div>
</li>
<li><a href="https://addons.mozilla.org/en-US/thunderbird/addon/signature-switch/" target="_blank">Signature Switch</a><br>
If you’re using Mozilla Thunderbird for more than one email accounts and wish to have different signatures between them, this is the plug-in for you. This will help you turn on/off and switch between signatures while composing the email. <a href="/wp-content/uploads/2011/01/SignatureSwitch.png" rel="lightbox[6386]"><img title="Signature-Switch" src="/wp-content/uploads/2011/01/SignatureSwitch_thumb.png" alt="Signature-Switch" width="232" height="174"></a></li>
<li><a href="https://addons.mozilla.org/en-us/thunderbird/addon/pastecode/" target="_blank">PasteCode</a><br>
If you’re a software developer and often email code snippets in Java/C/C++ or javascript, this extension automatically formats the keywords in the code making it readable.&nbsp; You need to use the new right click option “Paste Code” after installing this extension.<br>
<a href="/wp-content/uploads/2011/01/PasteCode.png" rel="lightbox[6386]"><img title="Paste-Code" src="/wp-content/uploads/2011/01/PasteCode_thumb.png" alt="Paste-Code" width="503" height="323"></a></li>
<li><a href="https://addons.mozilla.org/en-US/firefox/addon/dafizilla-table2clipboard/" target="_blank">Table2Clipboard</a><br>
A less popular but very useful plugin to ensure that tables from the email are copied properly into external tools like Microsoft excel/word without corruption the columns. I’ve personally been using it for years as I use tables a lot in my emails. <a href="/wp-content/uploads/2011/01/Table2Clipboard.png" rel="lightbox[6386]"><img title="Table2Clipboard" src="/wp-content/uploads/2011/01/Table2Clipboard_thumb.png" alt="Table2Clipboard" width="379" height="205"></a></li>
<li><a href="http://www.mozilla.org/projects/calendar/lightning/" target="_blank">Lightning</a> / <a href="https://addons.mozilla.org/en-US/thunderbird/addon/lightningbutton/" target="_blank">Lightning Button</a> / <a href="https://addons.mozilla.org/en-US/thunderbird/addon/calendar-tweaks/" target="_blank">Calendar Tweaks</a><br>
These are actually 3 extensions which go together to give you a complete calendar experience using Mozilla Thunderbird.<p></p>
<ul>
<li>
<div>Lightning although still a ‘beta’ product (are you reading this Mozilla? Countries at war even made peace while we wait for the final build) provides you event scheduling capabilities from within Mozilla Thunderbird. It supports the usual protocols to read your calendar off the server and you can also create an offline calendar.<br>
<a href="/wp-content/uploads/2011/01/ThunderbirdLightningMonthView.png" rel="lightbox[6386]"><img title="Thunderbird-Lightning-MonthView" src="/wp-content/uploads/2011/01/ThunderbirdLightningMonthView_thumb.png" alt="Thunderbird-Lightning-MonthView" width="472" height="461"></a></div>
</li>
<li>
<div><a href="https://addons.mozilla.org/en-US/thunderbird/addon/lightningbutton/" target="_blank">Lightning Button</a> – Just having Lightning extension installed doesn’t just help till you get the calendar buttons on your toolbar. This extension provides you one click buttons to create a new task/event etc.<br>
<a href="/wp-content/uploads/2011/01/ThunderbirdLightningButtonAll.png" rel="lightbox[6386]"><img title="Thunderbird-LightningButton-All" src="/wp-content/uploads/2011/01/ThunderbirdLightningButtonAll_thumb.png" alt="Thunderbird-LightningButton-All" width="468" height="44"></a></div>
</li>
<li>
<div><a href="https://addons.mozilla.org/en-US/thunderbird/addon/calendar-tweaks/" target="_blank">Calendar Tweaks</a> – The default lightning installation doesn’t highlight recurring events. This plug-in mimics how the calendar looks like in MS Outlook.<br>
<a href="/wp-content/uploads/2011/01/ThunderbirdLightningCalendarTweaks.png" rel="lightbox[6386]"><img title="Thunderbird-Lightning-Calendar-Tweaks" src="/wp-content/uploads/2011/01/ThunderbirdLightningCalendarTweaks_thumb.png" alt="Thunderbird-Lightning-Calendar-Tweaks" width="443" height="229"></a><p></p>
</div>
</li>
</ul>
</li>
<li><a href="https://addons.mozilla.org/en-US/thunderbird/addon/minimizetotray-plus/" target="_blank">Minimize to Tray Plus</a><br>
This application does exactly what the title says. It minimizes the Mozilla thunderbird instance into the applications tray bar. Thunderbird will continue to keep checking for emails in the background and can alert you when a new email arrives. The application can be restored from the task tray. You can even over-ride Thunderbird to minimize to tray even when the ‘close button’ is pressed.<br>
<a href="/wp-content/uploads/2011/01/ThunderbirdMinimizeToTrayPlus.png" rel="lightbox[6386]"><img title="Thunderbird-Minimize-To-Tray-Plus" src="/wp-content/uploads/2011/01/ThunderbirdMinimizeToTrayPlus_thumb.png" alt="Thunderbird-Minimize-To-Tray-Plus" width="291" height="37"></a></li>
<li><a href="https://addons.mozilla.org/en-US/thunderbird/addon/keyword-highlight/" target="_blank">Keyword Highlight</a><br>
Ever missed out an important email because you didn’t scan the content well enough? This extension highlights word(s) in a customizable color which then are easily noticeable so that you won’t miss that email again.<br>
<a href="/wp-content/uploads/2011/01/ThunderbirdKeywordHighlight.png" rel="lightbox[6386]"><img title="Thunderbird-Keyword-Highlight" src="/wp-content/uploads/2011/01/ThunderbirdKeywordHighlight_thumb.png" alt="Thunderbird-Keyword-Highlight" width="475" height="155"></a></li>
<li><a href="https://addons.mozilla.org/en-US/thunderbird/addon/mark-all-read-button/" target="_blank">Mark All As Read Button</a><br>
When you’re back from a vacation your mail box is full of unread emails most of which you’d want to mark all the emails or a particular thread as read. This’ll save your time by marking most of the irrelevant threads as read with just a single button click.<br>
<a href="/wp-content/uploads/2011/01/ThunderbirdMarkAllAsReadButton.png" rel="lightbox[6386]"><img title="Thunderbird-Mark-All-As-Read-Button" src="/wp-content/uploads/2011/01/ThunderbirdMarkAllAsReadButton_thumb.png" alt="Thunderbird-Mark-All-As-Read-Button" width="336" height="64"></a></li>
<li><a href="https://addons.mozilla.org/en-US/thunderbird/addon/thunderbird-message-filter-imp/" target="_blank">Thunderbird Message Filters Export/Import</a><br>
Just as the title says, this helps you to export and import your huge list of filters for those who don’t/can’t use server side filters. It’s a pain to re-create the same filters across multiple machines. If only there is a <a href="https://mozillalabs.com/sync/" target="_blank">Mozilla Sync</a> for Thunderbird as well.</li>
</ol>
