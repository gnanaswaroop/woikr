<p><a href="http://www.nextbigwhat.com/irctc-next-generation-online-ticketing-297/?utm_source=feedly&amp;utm_reader=feedly&amp;utm_medium=rss&amp;utm_campaign=irctc-next-generation-online-ticketing">NextBigWhat is reporting</a> that IRCTC seem to have improved its site’s performance making it usable during peak ticketing hours. They seem to have added servers and/or optimized the site’s software performance in order to give a smoother ticketing experience to users during peak hours.</p>
<p>The site seems to have gone lightweight in UI design thereby reducing the load times of the web pages. Given that the site is a transactional site which needs to be secure &amp; efficient enough to handle millions of hits during peak hours, any optimization &amp; hardware upgrade needs to be thoroughly tested before deployment. IRCTC made an announcement about this improvement last year.</p>
<p>This change should help a lot of users to book tickets (relatively) faster during peak hours.</p>
