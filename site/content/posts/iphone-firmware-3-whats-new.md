<p>The news about <a href="http://www.engadget.com/2009/03/12/iphone-os-3-0-is-coming-march-17th/" target="_blank">Apple inviting journalists to reveal features on the upcoming iPhone firmware 3.0</a> is all over the web.</p>
<p>As every one knows earlier <a href="http://www.apple.com/pr/library/2008/03/06iphone.html" target="_blank">iPhone 2.0</a> firmware brought lots of good stuff like the AppStore and MS Exchange support. So we're expecting Apple to bring out something good this time too.</p>
<p>According to Apple's invite for March 17th event, they're going reveal the features so that developers can get started to work in the direction with the new features/SDK API's released with iPhone 3.0.</p>
<p><a href="/wp/wp-content/uploads/2009/03/iphone_30_firmware_lead_image.jpg"><img class="alignnone size-full wp-image-2238" title="iphone_30_firmware_lead_image" src="/wp/wp-content/uploads/2009/03/iphone_30_firmware_lead_image.jpg" alt="iphone_30_firmware_lead_image" width="269" height="178" /></a></p>
<p>Now, woikr composes a list of possible features and how best an application can use them.</p>
<p><strong>Possible goodies in iPhone firmware 3.0</strong></p>

<p><strong>Push Notification</strong> - This feature was <a href="http://gizmodo.com/5058609/apple-misses-iphone-push-notification-september-deadline" target="_blank">promised long back</a> in September and Apple had clearly missed it. We're hoping they stick to the promise and bring this out.<br>
Having this feature would mean a ton to iPhone developers which would make the applications receive notifications by the 'Apple Server' even though the app isn't running on the phone. A very common usage of one would be in terms of Instant messaging clients.
<p><strong>MMS Capability</strong> - Apple never admitted that the iPhone camera is good for video. But with third party software like Qik and Snapture have quite proved that the iPhone camera is good for the same.</p>

<p><strong>Background Applications</strong> - This should enable other 3rd party applications to run in the background. Currently only the Phone and the iPod application can do that.<br>
This comes with pros and cons of course. The positive side of which would mean the user doesn't need to close the application. It'll be always 'running'. The negatives would also 'phone out of memory issue' or 'battery draining' etc. For the Jailbreak fans, Backgroundr is a 3rd party app which allows exactly the same.
<p><strong>The Wish list</strong> - which we hope gets shorter</p>

<p><strong>Bluetooth Stereo &amp; file transfer</strong> - There are speculations that Apple has little interest in support <a href="http://en.wikipedia.org/wiki/Bluetooth_profile" target="_blank">A2DP</a> protocol but instead wants to build its own Bluetooth profile instead.<br>
That said, for the jailbreak fans, the recently released paid application (4 Euros) called as <a href="http://www.medevil.net/?p=85" target="_blank">iBluetooth</a> does support bluetooth file transfers between devices.<br>
There are <a href="http://www.ibluetoothproject.tk/" target="_blank">people</a> who're trying to build or port bluetooth profiles to the iPhone.
<p><strong>Copy Paste</strong> - This was one of the most talked about feature of all time. Users have been <a href="/apple/woikr-clarifies-allegations-on-the-iphone-3g-in-india-chain-mail/" target="_blank">cribbing about not having copy paste</a> this for a while now. But the recent availability of hClipboard and Clippy fpr jailbroken iPhones have turned the table.</p>
<p><strong>Flash Support</strong> - Adobe was always <a href="http://www.flashdevices.net/2008/03/adobe-flash-player-coming-to-iphone.html" target="_blank">willing to bring flash to the iPhone</a> but  Apple's not. We've hardly missed it on most of the frequently visited sites. Thanks to good web design by having low bandwidth version without using flash.</p>
<p>Only on March 17th would we know what Apple's Wish-Granted features would be. So stay tuned.</p>
