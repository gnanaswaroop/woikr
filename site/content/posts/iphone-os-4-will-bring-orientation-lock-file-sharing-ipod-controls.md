<p><img title="image" alt="image" src="/wp/wp-content/uploads/2010/05/image9.png" width="150" height="111" /> </p>  <p>As developers start using Apple’s latest iPhone OS 4 beta 3, they find hidden/updated features. <a href="http://www.boygeniusreport.com" target="_blank">BGR</a> has revealed a few features which everyone always wanted:</p>  <ul>   <li>     <div><strong>File Sharing</strong>         <br />You will now be able to transfer files between your iPhone and you computer. There will be a new “Apps” tab in iTunes where all the user modifiable files for a given app will be available for downloading to your computer. You will also be able to upload files to your iPhone using this screen. </div>      <div></div>      <div><img title="image" alt="image" src="/wp/wp-content/uploads/2010/05/image10.png" width="480" height="329" /> </div>   </li>    <li>     <div><strong>Orientation Lock</strong>         <br />This is something that I have always wanted. Currently I have to use the jailbroken app “Rotation Inhibitor” for this. It will be great to have an inbuilt support for this. Using this feature, you can lock the screen in portrait mode so that it does not rotate to landscape when you tilt the device. This is particularly useful when you want to read something while laying down. To enable orientation lock, you simply have to fire up the multitasking interface, swipe to the left and click the Portrait Lock icon.         <br /><img title="image" alt="image" src="/wp/wp-content/uploads/2010/05/image11.png" width="324" height="484" /> </div>   </li>    <li>     <div><strong>New Media Player controls</strong>         <br />The multitasking dock now offers iPod controls. To access them, just swipe left.         <br /><img title="image" alt="image" src="/wp/wp-content/uploads/2010/05/image12.png" width="324" height="484" /> </div>   </li>    <li>     <div><strong>Faster way to close apps</strong>         <br />To close apps running in background, now you just have to press and hold the icon of one of the applications currently running, and you’ll be given the option to close them.        <br /><img title="image" alt="image" src="/wp/wp-content/uploads/2010/05/image13.png" width="324" height="484" /> </div>   </li> </ul>  <p>[<a href="http://www.boygeniusreport.com/2010/05/04/hot-new-features-uncovered-in-iphone-os-4-0-beta-3/" target="_blank">BGR</a> via <a href="http://iphoneindia.gyanin.com/2010/05/05/iphone-os-4-to-bring-orientation-lock-file-sharing-and-ipod-controls-to-multitasking-bar/?utm_source=feedburner&amp;utm_medium=feed&amp;utm_campaign=Feed%3A+IphoneIndia+%28iPhone+India%29" target="_blank">iPhoneIndia</a>]</p>
