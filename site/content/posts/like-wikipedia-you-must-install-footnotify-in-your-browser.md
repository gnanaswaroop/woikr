<p>You know the most irritating thing about Wikipedia? The references. Going up and down the text/references is terribly distractive and sometimes I even get lost within the page. The good news is that <a href="http://twitter.com/hpeikemo" target="_blank">Hans from Norway</a> already came up with a solution - <a href="http://openideas.ideon.co/2011/rehabilitate-disruptive-footnotes" target="_blank">Footnotify</a>.</p>
<p>Footnotify is a Chrome/Safari extension that allows you to see references in Wikipedia in a clean popup. You can open the link in new window if you so wish and move ahead. The extension also works on <a href="http://daringfireball.net/" target="_blank">DaringFireball</a> and <a href="http://brooksreview.net" target="_blank">BrooksReview</a>.</p>
<p><img class="alignnone size-full wp-image-8341" title="footnotify_screenshot" src="/wp/wp-content/uploads/2011/08/footnotify_screenshot.jpg" alt="" width="580" height="262" /></p>
<p>The extension was originally created for <a href="http://static.ideon.co/chromeextensions/footnotify.crx" target="_blank">Chrome</a> and <a href="http://static.ideon.co/safariextensions/footnotify.safariextz" target="_blank">Safari</a>. <a href="http://twitter.com/kottkrig" target="_blank">@kottkrig</a> has ported it to <a href="https://addons.mozilla.org/en-US/firefox/addon/footnotify/" target="_blank">Firefox</a> as well. Go ahead and install it. It's a must-have.</p>
