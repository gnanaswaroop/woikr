<p>Apple's next iteration of its OS X operation system, <a href="http://www.apple.com/macosx/">Lion</a> is out now and <a href="http://itunes.com/mac/osxlion">available now on the Mac App Store</a> as promised. Apple previously revealed in their <a href="/apple/all-about-apples-new-software-products-announced-at-wwdc-2011/">WWDC keynote</a> that OS X Lion will be available in July.</p>
<p>Lion is only available through the Mac App store and to get it you must be on Snow Leopard version 10.6.6. If you are not, you can run Software update to update your system.</p>
<p>Lion packs some pretty awesome features and is expected to be the last of the cat family series of OS from Apple. You can read <a href="/apple/all-about-apples-new-software-products-announced-at-wwdc-2011/">woikr's initial analysis</a> of Lion's features here until we test the new OS and write a detailed review.</p>
<p>You can download Lion from the Mac App store for <a href="http://itunes.com/mac/osxlion">$29.99 here</a>.</p>
