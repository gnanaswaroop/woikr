<p>Google has launched a new version of Gmail for the iPhone. This new more Ajaxy version utilizes the HTML5 library in the latest Safari browser in 2.2.1 firmware. The new features are:</p>

<ol>
	<li>Faster interface</li>
	<li>Offline support</li>
	<li>Cool floaty bar (a hot bar which appears when you select a message)</li>
	<li>Improved labels</li>
</ol>
<a href="/wp/wp-content/uploads/2009/04/gmailpost.jpg"><img class="alignnone size-full wp-image-2407" title="gmailpost" src="/wp/wp-content/uploads/2009/04/gmailpost.jpg" alt="gmailpost" width="400" height="295" /></a>
<p>According to the Google mobile blog:</p>

<blockquote>All this is achieved with aggressive caching and by leveraging new browser technologies, like <a href="http://en.wikipedia.org/wiki/Html5" target="_blank">HTML5</a> and Gears. The full impact of this new architecture isn't visible yet, but it will enable us to significantly improve performance and quickly roll out new features in the near future. We're really excited about the potential impact this change can bring - so excited, in fact, that our VP of Engineering, Vic Gundotra, shared the news and demoed these new capabilities at the February 2009 GSMA Mobile World Congress event in Barcelona and last week at Web 2.0 in San Francisco.</blockquote>
<p>The new interface is available for Android and iPhones with firmware &gt;= 2.2.1. Other users will be redirected to the old interface. Currently, it is supported in English only. Google is rolling out this in phases, so in case its still not available for you, check back later.</p>
