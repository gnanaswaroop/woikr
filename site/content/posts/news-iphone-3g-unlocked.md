<p>Its finally here. iphone-dev folks have cracked the iPhone 3G baseband. This means that we can now unlock iPhone 3G and use them with any network in the world.&nbsp; Of course this will void your warranty and will also be considered illegal in some countries where you bought the phone under contract.</p>
<p>Here is an excerpt from the iphone-dev blog:</p>
<blockquote><p>We have been working hard on a few other things. The main one being the 3G unlock codenamed “<strong>yellowsn0w</strong>”. This is now completed and is currently being packaged into a user-friendly application with the simplicity that you see in QuickPwn or BootNeuter.</p>
<ul>
<li>The target release date for the unlock is New Year’s Eve 2008.</li>
<li>This unlock method is available to iPhone 3Gs that have 2.11.07 baseband or earlier, we did <a href="http://blog.iphone-dev.org/post/61060174/the-man-from-delmonte-he-say-yes" target="_blank">warn you</a>.</li>
<li>You can tell what version baseband you have by going to Settings-&gt;General-&gt;About-&gt;Modem Firmware</li>
<li>The unlock requires a jailbroken 3G iPhone.&nbsp; It’ll be installable via Cydia and so it doesn’t matter if you have a Mac or PC.</li>
<li>Please refrain from updating your baseband, regardless of what version you’re at.&nbsp; We’ll have complete directions on New Year’s Eve.</li>
<li>We’ll stream a live demo of the unlock before Christmas (see the update at the end of this post)</li>
</ul>
</blockquote>
<p>There will also be a live demo of the unlock sometime before christmas via Qik. This will be announced on MuscleNerd’s twitter page just before when the demo is about to start. So start following MuscleNerd people!</p>
