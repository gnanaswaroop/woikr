<p><img title="image" height="175" alt="image" src="/wp/wp-content/uploads/2010/09/image27.png" width="175" /> </p>  <p>After months of waiting, Twitter has finally released the <a href="http://blog.twitter.com/2010/09/twitter-for-ipad-sharing-content-in.html" target="_blank">official twitter app for iPad</a>. And as expected, its super awesome. So awesome that <a href="http://techcrunch.com/2010/09/01/twitter-for-ipad/" target="_blank">MG Siegler of TechCrunch</a> has said that its the best iPad app yet.</p>  <p>With apps like <a href="http://www.flipboard.com/" target="_blank">Flipboard</a>, <a href="http://reederapp.com/ipad/" target="_blank">Reeder</a>, and <a href="http://techcrunch.com/2010/05/31/pulse-ipad/" target="_blank">Pulse</a>, expectations were very high from for the twitter’s official iPad app. And the Twitter team has totally delivered. The app has been developed by Loren Brichter <a href="http://twitter.com/lorenb" target="_blank">(@lorenb</a>) and Bryan Haggerty (<a href="http://twitter.com/bhaggs" target="_blank">@bhaggs</a>). Loren Brichter is the developer of the official twitter client for the iPhone (previously called <a href="http://www.atebits.com/tweetie-iphone/" target="_blank">Tweetie</a>).</p>   <p><a href="/wp/wp-content/uploads/2010/09/image28.png"><img title="image" height="184" alt="image" src="/wp/wp-content/uploads/2010/09/image_thumb4.png" width="244" /></a> </p>  <p>The app utilizes all the smooth UI elements of the iPad. When you start the app, you are presented with the options to either log in or read tweets from different categories like Art &amp; Design, Sports, and News. Once you sign in, a left nav gives you the standard menu with mentions, lists, messages etc.</p>  <p><a href="/wp/wp-content/uploads/2010/09/image29.png"><img title="image" height="244" alt="image" src="/wp/wp-content/uploads/2010/09/image_thumb5.png" width="184" /></a>&#160; <a href="/wp/wp-content/uploads/2010/09/image30.png"><img title="image" height="184" alt="image" src="/wp/wp-content/uploads/2010/09/image_thumb6.png" width="244" /></a> </p>  <p>When you tap on a tweet, a pane is opened towards the right half of the screen. If there is any link in that tweet, it is displayed in that pane. If there is a video linked in a tweet, you can start buffering the video in that pane and continue reading other tweets in the main pain. This is a killer feature which is not available in any other app.</p>  <p><a href="/wp/wp-content/uploads/2010/09/image31.png"><img title="image" height="244" alt="image" src="/wp/wp-content/uploads/2010/09/image_thumb7.png" width="184" /></a> </p>  <p></p>  <p>The app has a lot of gestures that you can use. Pinch on a tweet to reply or retweet. Pull down using two fingers to see a conversation. And yes, of course, the trademark drag and release to refresh gesture is there too!</p>  <p>The app has an amazing UI but you might need some time to get used to it as there is a slight learning curve for the gestures.</p>  <p>The app uses the same binary for iPhone and iPad. So, there is only one app in the App store. If you use the official twitter app on your iPhone, just download it on the iPad.</p>  <p>[via <a href="http://blog.twitter.com/2010/09/twitter-for-ipad-sharing-content-in.html" target="_blank">Twitter blog</a>]</p>
