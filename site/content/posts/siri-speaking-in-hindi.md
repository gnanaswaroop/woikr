<p>Siri supports a few languages right now and Apple is working on new ones. However, <a href="https://twitter.com/#!/kunalkaul123/status/189728631348674560">@kunalkaul123</a> has made Siri speak Hindi on his iPhone using a proxy server. Kunal is forwarding the Siri requests to his Google API server for translation. Here is a video of the hack in action:</p>
<p>httpv://www.youtube.com/watch?v=JAojzCKYk2c</p>
<p>Pretty cool eh? It would be great if Apple adds Hindi support for Siri. It would be an awesome way to sell iPhones in india.</p>
