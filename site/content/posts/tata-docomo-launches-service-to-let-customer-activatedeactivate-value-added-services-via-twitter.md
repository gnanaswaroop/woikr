<p>Tata Docomo has launched an innovative way for activating &amp; deactivating value added services via twitter. Here are the steps one needs to perform in order to use the service:</p>
<ul>
<li>Tweet #reg &lt;Mobile Number&gt; to @tatadocomo</li>
<li>You will receive a pin code for verification through SMS</li>
<li>Tweet #code &lt;Pincode&gt; to @tatadocomo</li>
<li>Tata Docomo will retweet confirming registration</li>
<li>For activating value added services, tweet #act# &lt;Service&gt;&lt;value&gt; to @tatadocomo</li>
<li>You will get a tweet back confirming activation of the service.</li>
</ul>
