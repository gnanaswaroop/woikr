<p><a href="http://www.teamviewer.com/" target="_blank">Team Viewer</a> is a free download available for Windows and Mac which allows seamless desktop sharing and remote control. The interface is very intuitive. You can connect to another computer anywhere in the world without even knowing its IP address! It also works perfectly behind firewalls.</p>

<h3>Features:</h3>
<ul>
	<li>Integrated file transfers</li>
	<li>Works behind firewalls</li>
	<li>Encrypted data transfer</li>
	<li>Free for private use !</li>
</ul>
<div>Here is the <a href="http://www.teamviewer.com/download/TeamViewer_Setup.exe" target="_blank">download link.</a> Just unzip the downloaded file and run the setup.</div>
<div>Once you start TeamViewer, you will be presented with a screen similar to the following:</div>
<div><a href="/wp/wp-content/uploads/2008/10/teamviewer_screen1.png">
<img class="alignnone size-medium wp-image-1194" title="teamviewer_screen1" src="/wp/wp-content/uploads/2008/10/teamviewer_screen1-300x209.png" alt="" width="300" height="209" /></a></div>
<div>There are 3 modes in which you can use TeamViewer:<br>
1. <strong>Remote Support </strong>-  This mode supports Desktop sharing and remote control on your desktop.<br>
2. <strong>Presentation</strong> - This mode will just show your desktop to others. They cannot control it.<br>
3. <strong>File Transfer</strong> - This mode can be used to share files with others.</div>
<div>You can connect to another computer anywhere in the world by specifying its ID under "Partner Details". The other computer must be running TeamViewer. You will also need user's permission or the password to the other computer to be able to connect to it.</div>
<div>In order to make your computer accessible via firewalls &amp; routers, make sure that DynGate (which is bundled with TeamViewer) is running. When you start TeamViewer, you will see your ID under "Your Details". Give this ID to people who want to access your computer remotely.</div>
<div><a href="/wp/wp-content/uploads/2008/10/teamviewer_screen2.png">
<img class="alignnone size-medium wp-image-1195" title="teamviewer_screen2" src="/wp/wp-content/uploads/2008/10/teamviewer_screen2-300x219.png" alt="" width="300" height="219" /></a></div>
<div>Another great feature is the Host Mode using which TeamVIewer will be constantly running in your system tray and you can connect to your computer from anywhere in the world. For security purposes, you will need to set a password for this mode. This can be done under Extras -&gt; Options -&gt; Host Mode.</div>
<div><strong><br>
Q</strong>. How is it superior to the Windows Remote Desktop app?<br>
<strong>A</strong>. Remote Desktop is a good app. However, you need to enable it on your computer. Then you need to add your user account to the Remote Users group. Then you might need to modify your security policy. It might not even work after all this if there is a firewall in between. And accessing a Windows Vista computer using Remote Desktop is a nightmare. TeamViewer is far more better. Period.</div>
<div><strong><br>
Q</strong>. How is it better than VNC?<br>
<strong>A</strong>. 1 - VNC is slow. The screen does not refresh unless you move your mouse all over it. 2 - VNC does not support the file transfer mode. 3 - TeamViewer is much more easier to use as it uses IDs and not IPs, It is also secure as it transfers all data encrypted.</div>
<div><strong><br>
Q</strong>. Where can I use it?<br>
<strong>A</strong>. Geographically distributed teams. Helpdesk/support system. Deliver presentations. Remote demonstrations. Checking on torrent download status on your home computer from work !</div>
<div><strong><br>
Remember </strong>- Your ID is unique. It is really important that you keep it secure. Do not give it away to anybody unless you trust them.</div>
