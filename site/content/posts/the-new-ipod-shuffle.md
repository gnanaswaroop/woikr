<p>Apple launched the new <a href="http://www.apple.com/ipodshuffle/" target="_blank">iPod Shuffle</a> this week. It has been completely revamped. Made out of aluminum, it is much smaller in size, boasts of double the storage at 4 GB and the controls have been moved to the right earbud cord.  And it talks.</p>
<p>Despite that fact that shifting the controls to the earbud wire will make it easier for users to operate the device, it kinda sucks in a way that you will have to stick with the crappy white earbuds which ship with it. So no <a href="http://www.boseindia.com/retail/bose-product-detail.aspx?Prd_Id=57&amp;Cat_Id=647&amp;Nav_Id=647" target="_blank">Bose</a>, no <a href="http://www.sennheiserindia.com/india/icm_eng.nsf/root/500830" target="_blank">Sennheiser</a>. A <a href="http://www.nokia.co.in/link?cid=EDITORIAL_492634" target="_blank">Nokia type solution</a> with a 3.5 mm stereo jack in the control would have have been better. This might be temporary as Apple fixed a similar issue in the iPhone 3G by introducing the flush headphone jack.</p>

<a href="/wp/wp-content/uploads/2009/03/new_ipod_shuffle_controls.png"><img class="alignnone size-medium wp-image-2226" title="new_ipod_shuffle_controls" src="/wp/wp-content/uploads/2009/03/new_ipod_shuffle_controls-300x127.png" alt="new_ipod_shuffle_controls" width="300" height="127" /></a>
<p>The <a href="http://www.apple.com/ipodshuffle/voiceover.html" target="_blank">VoiceOver</a> feature sounds cool. But imagine it announcing the title and artists for tracks which do not have that info.  You will end up hearing "Untitled Track" and "No Artist" for most of your MP3s. LOL.</p>
<p>The size has been drastically reduced. The following images will give you an idea:</p>

<p>The storage space has been increased to 4GB. This means that you can fit in upto 1000 songs in this teeny weeny beauty:</p>

<p>The basic features remain the same with a belt clip and a switch to select the play mode/switch off the device:</p>

<p>All in all, its a nifty upgrade to the (now) ugly looking <a href="http://en.wikipedia.org/wiki/IPod_Shuffle#Second_generation" target="_blank">old shuffle</a>. The new shuffle is priced at $79 in the US, is <a href="http://www.apple.com/in/ipodshuffle/" target="_blank">now available</a><a href="http://www.apple.com/in/ipodshuffle/" target="_blank"> in India</a> and should retail for approx INR 3200.</p>
