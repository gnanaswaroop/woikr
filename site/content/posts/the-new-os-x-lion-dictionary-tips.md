Amongst the <a href="http://www.apple.com/in/macosx/whats-new/" target="_blank">over 250</a> new features in Mac OS X Lion, one that I may end up using a lot is the new system-wide dictionary. So while Snow Leopard had a dictionary that could be called anytime anywhere but it was not really apparent. The shortcut was mostly unknown and sorta obscure and it just didn't work flawlessly everywhere.

In Lion, that has been improved. Now the dictionary works across the OS, flaunts a much neater UI and has  a cool new multitouch gesture that will eventually make more people use it.



<img class="alignnone size-full wp-image-8205" title="Mac OS X Lion Dictionary" src="/wp/wp-content/uploads/2011/07/Screen-Shot-2011-07-24-at-1.22.59-AM.jpg" alt="Mac OS X Lion Dictionary" width="341" height="500" />
<h4>How to access the Dictionary?</h4>
Go to System Preferences-&gt;Trackpad-&gt;Point &amp; Click and make sure Look up is checked. Now whenever you double tap on a word using three fingers anywhere in a Lion app, it will show you an embedded dictionary showing the meaning of the word, Thesaurus entry, Apple dictionary entry and even a few lines from the word's Wikipedia page.

Note that the gesture might not be the easiest or the most convenient one, but you will get the hang of it pretty quickly. If you don't or you have configured three finger taps for <a title="Middle Click on your Macbook/Magic Mouse" href="/mac/middle-click-on-your-macbook-magic-mouse/" target="_blank">other better functions</a>, there is always a handy keyboard shortcut - <strong>Ctrl + Cmd + D</strong>.

Bonus Tip: You can activate the Dictionary even when you are QuickLook-ing a file!

Try it. Heck, force yourself to use it often. After all, for a writer, knowing the exact meaning every word you use is precious.
