<p>The race to be the fastest mobile processor reached an interesting new high today after Qualcomm announced their Quad-Core chipset for mobile phones which clock at 2.5Ghz. This was in response to the earlier <a href="http://www.engadget.com/2011/01/24/nvidia-tegra-3-equipped-with-1-5ghz-quad-core-madness-teased-b/">NVIDIA's Quad-Core TEGRA 3 processor rumor/leak</a> – which runs at 1.5Ghz. Every mobile phone you own now, has now become obsolete and slow – Damn you &quot;Chipset manufacturers&quot; Happy now? </p>  <p>Personally I hate it that when hardware gets faster, people write bad software (as it runs fast anyway) leaving us to be doomed sometime in the future (instead of now). </p>  <p><a href="/wp/wp-content/uploads/2011/02/QualcommSnapdragon.jpg"><img title="Qualcomm-Snapdragon" alt="Qualcomm-Snapdragon" src="/wp/wp-content/uploads/2011/02/QualcommSnapdragon_thumb.jpg" width="141" height="57" /></a> </p>  <div></div>  <p>So you might ask, what's the benefit of having a faster processor on a mobile phone which you're only going to use for calls/send emails? No, you'll soon be doing more stuff with it, like</p>  <ul>   <li>     <div>Better and faster multi-tasking - It's got 4 cores which run 2.5Ghz (per core) – </div>   </li>    <li>     <div>This is 12x faster than the original Snapdragon and uses less power (There you go, you're just saved the battery life too).</div>   </li>    <li>     <div>Does better video processing out of the box (records and plays at higher FPS).</div>   </li>    <li>     <div>Will include the latest Adreno GPU (can play games upto 60fps) and display 3D video and output <a href="/mobile-phones/xperia-pro-neo-and-the-playstation-phone-announced">1080p video playback to a TV over HDMI</a>. </div>   </li> </ul>  <p>The chipset is being built on a new microprocessor technology by the name of &quot;Krait&quot;. These chipsets will contain the 4 connectivity solutions – WiFi, GPS, Bluetooth &amp; Radio. They will also incorporate NFC, <a href="/android/lg-g-slate-preview-3d-viewing-and-recording-honeycomb-tablet">3D record and playback</a>.</p>  <p>The technology is yet to be adopted by the phone hardware companies, so don’t expect this to be out anytime before next year (2012). If you're looking for the fastest phone in the market now, you should start <a href="http://www.phonegg.com/Top/Fastest-Processor-Cell-Phones.html">here</a>.</p>  <p>[Via <a href="http://www.qualcomm.com/news/releases/2011/02/14/qualcomm-announces-next-generation-snapdragon-mobile-chipset-family">Qualcomm Press</a> &amp; <a href="http://www.mobilecrunch.com/2011/02/13/snapdragon-bites-back-qualcomm-announces-a-quad-core-2-5ghz-chipset-for-mobile-devices/">MobileCrunch</a>]</p>
