<p>Google held a Chrome OS event yesterday at the their Mountain View office. Here are the findings:</p>  <ul>   <li>Its an open source OS </li>    <li>Its very simple and lightweight, initially targeted to run on netbooks. </li>    <li>Its basically a browser which is gonna run web apps </li>    <li>Will support <a href="http://en.wikipedia.org/wiki/X86" target="_blank">x86</a> and <a href="http://en.wikipedia.org/wiki/ARM_architecture" target="_blank">ARM</a> processors </li>    <li>You will have to buy Google approved netbooks to use it </li>    <li>Will be release sometime next year </li> </ul>  <p>Here is the first official screenshot (click for a larger
