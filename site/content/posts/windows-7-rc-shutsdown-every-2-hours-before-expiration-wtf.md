<p>This happens to be our first Windows 7 post. We kept restraint and avoided reporting how "cool" Win7 looks/is, but we couldn't resist sharing what Win7 RC has in store.</p>
<p><a href="/wp/wp-content/uploads/2009/05/windows_7_rc_shutdown.jpg"></a><a href="/wp/wp-content/uploads/2009/05/windows_7_rc_shutdown_suck_rc_testers.jpg"><img class="alignnone size-full wp-image-2739" title="windows_7_rc_shutdown_suck_rc_testers" src="/wp/wp-content/uploads/2009/05/windows_7_rc_shutdown_suck_rc_testers.jpg" alt="windows_7_rc_shutdown_suck_rc_testers" width="353" height="322" /></a></p>
<p>So Windows 7 RC starts to shutdown every two hours after the "doomsday". And it even alerts the user starting two weeks before this feature  kicks in.</p>

<blockquote>Watch the calendar. The RC will expire on June 1, 2010. Starting on March 1, 2010, your PC will begin shutting down every two hours. Windows will notify you two weeks before the bi-hourly shutdowns start. To avoid interruption, you’ll need to install a non-expired version of Windows before March 1, 2010. You’ll also need to install the programs and data that you want to use. (Learn more about installing Windows.)</blockquote>
